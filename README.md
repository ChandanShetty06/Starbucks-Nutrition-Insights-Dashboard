# ☕ Starbucks Nutrition Insights Dashboard

## 📊 Project Overview
The **Starbucks Nutrition Insights Dashboard** is an interactive analytics project designed to explore Starbucks beverage data. It highlights nutrition metrics such as calories, caffeine, sugar, and protein, while also showcasing beverage category distribution and Starbucks’ global presence.

This project demonstrates skills in **data analysis, visualization, and storytelling**, combining technical accuracy with executive‑level presentation.

---

## 🔑 Key Insights
- **Average Calories by Category** – Compare calorie levels across beverage types.
- **Beverage Category Distribution** – Visual breakdown of Starbucks’ beverage portfolio.
- **Average Caffeine by Category** – Analyze caffeine content across categories.
- **Top 5 Highest Caffeine Beverages** – Identify the strongest drinks on the menu.
- **Global Presence** – Explore Starbucks’ reach and beverage popularity worldwide.

---

## 🛠 Tools Used
- **Power BI** – Interactive dashboard creation  
- **Excel** – Data cleaning and preparation  
- **Tableau** – Advanced visualization (optional)  
- **Canva** – Branding and design polish
